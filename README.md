# java-sprint4-hw
Приложение по управлению работой театра.
Классы (общие сущности): 
спектакль (Show), 
актёр (Actor) 
режиссёр (Director). 

Show: 
название (title), 
длительность в минутах (duration), 
режиссёр (director) 
список актёров (listOfActors)

Actor:
имя (name), 
фамилия (surname), 
пол (gender) - Перечисление (enum) с двумя значениями: MALE (мужской) и FEMALE (женский)
рост (height)

Director:
имя (name),
фамилия (surname),
пол (gender) - Перечисление (enum) с двумя значениями: MALE (мужской) и FEMALE (женский)
количество поставленных спектаклей (numberOfShows)


1. Создайте классы Show, Actor и Director. 
Для каждого из этих классов добавьте соответствующие поля и конструкторы.
2. Добавить класс Person и перенести поля, которые относятся к любому человеку, в этот класс. 
3. Создать новый класс MusicalShow «Музыкальный спектакль» — наследник Show, 
и два класса Ballet (балет) и Opera (опера) — наследники MusicalShow
4. Доработайте иерархию классов с учётом новых классов. 
В MusicalShow добавьте поля musicAuthor (автор музыки) и librettoText (текст либретто). 
Класс Ballet также должен содержать поле choreographer (хореограф), 
а класс Opera — choirSize (количество человек в хоре).
Добавьте для новых классов конструкторы, содержащие все поля.
5. Вам нужно реализовать следующие возможности:
   Распечатать текст либретто. (класс MusicalShow)
   Распечатать информацию о режиссёре спектакля — должны выводиться его имя и фамилия. (переопределить для этого метод toString)
   Распечатать список всех актёров, участвующих в спектакле. Для каждого актёра при этом должны выводиться имя и фамилия, а также в скобках его рост. (Show)
   Добавить нового актёра в спектакль. При добавлении актёра должна быть проверка, нет ли уже такого актёра среди добавленных. Если есть, должно выводиться предупреждающее сообщение, и актёр не должен добавляться. Актёры считаются одинаковыми, если у них совпадают имя, фамилия и рост.
   Заменить одного актёра в спектакле на другого (на вход подаётся объект нового актёра и фамилия того, которого он заменяет). Если актёр с такой фамилией отсутствует, должно выводиться предупреждающее сообщение. Порядок актёров в списке значения не имеет.
   Подумайте, какие методы для этого нужно добавить в какой из классов.


6. Внутри метода main вам нужно выполнить следующие действия:
   Создать трёх актеров и двух режиссёров. Также создайте одного автора музыки и одного хореографа
   Создать три спектакля: обычный, оперный и балет
   Распределить актёров по спектаклям. Используйте для этого метод добавления нового актёра в спектакль. Один актёр может участвовать в нескольких спектаклях.
   Для каждого спектакля выведите на экран список актёров.
   Замените актёра в одном из спектаклей на актёра из другого спектакля и ещё раз выведите для него список актёров.
   Попробуйте заменить в другом спектакле несуществующего актёра
   Для оперного и балетного спектакля выведите на экран текст либретто.**
